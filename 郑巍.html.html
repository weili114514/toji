游戏 2026.10.18

游戏时光

在游戏里过完一个下雨的周末

本来只想上线收一轮菜，再抬头时天已经黑了。那个没有排位的下午，反而成了十月里最放松的一段时间。

约 3 分钟

国庆假期的最后一天，外面从中午开始下雨。我没有出门，泡了杯茶，打开《星露谷物语》，本来只打算收一轮菜。

结果再抬头已经晚上九点。我把农场边那条小路重新铺了石板，给鸡舍换了木地板，还认真研究了一会儿哪种栅栏更配我的房子。没有任务，也没有排名，时间就这么慢慢地过去了。

关掉电脑以后，我下楼买了一碗面。雨还没停，店里只有老板在听收音机。我忽然觉得，放松不需要什么计划，一个不设闹钟的下午就够了。

生活 2026.10.09

大学感触

原来大学的第一课，是学会一个人吃饭

开学第六周，我第一次一个人去食堂。端着餐盘找位置的那几分钟，比想象中更长，也没有想象中难。

约 3 分钟

开学第六周，室友们各自有约。我本来想等一等，后来还是拿起饭卡，一个人去了食堂。

中午的食堂很吵，托盘碰在一起，窗口前排着队。我端着饭找位置的时候，突然有点想念高中那群总是抢我鸡腿的人。但也只是那一会儿。

后来我坐在靠窗的位置，旁边有一盆绿萝。吃完饭，我给妈妈发了张照片，她回：“看起来挺好吃的。”我笑了笑，把餐盘送到回收处。一个人吃饭并没有那么难，难的是承认自己已经要开始一个人处理很多事了。

生活 2026.09.27

运动时刻

傍晚六点，操场上的三公里

原本只想去走两圈，听见操场放起一首老歌，就跟着人群跑了起来。没破纪录，但风很舒服。

约 3 分钟

傍晚六点半，天刚暗下来。我本来只打算去操场走两圈，耳机里还放着没听完的播客。

走到弯道的时候，操场的大喇叭放起一首很旧的歌。前面一个穿白 T 恤的男生开始加速，我也莫名其妙地跟着跑了起来。

第一公里很轻松，第二公里开始后悔，第三公里只剩下呼吸声。跑完的时候衣服全湿了，膝盖有点软，但晚风吹过来，整个人像被重新启动了一次。

回宿舍的路上，我在便利店买了一瓶冰水。那天晚上没有熬夜，第二天的作业也写得出奇顺利。运动的回报有时候来得很直接。

学习 2026.09.15

C 语言学习

我的第一个 C 语言程序，报错三次

对着 PPT 敲完那几行代码，屏幕上的红色报错比我想象中多。最后发现，问题只是少了一个分号。

约 4 分钟

第一堂 C 语言课，老师让我们写一个输出 Hello, world 的程序。我照着 PPT 一个字一个字地敲，按下运行，结果跳出来三行红色报错。

我盯着屏幕看了很久，先是怀疑软件坏了，后来才发现是 printf 那一行少了一个分号。补上之后，黑色窗口里终于跳出一行白字，我居然有点激动。

#include <stdio.h>

int main(void) {
    printf("Hello, college!\n");
    return 0;
}

现在看，这几行代码当然简单得不能再简单。但那一刻我第一次觉得，屏幕里的东西是我让它出现的。后来每次 debug 到怀疑人生，我都会想起那个下午。

郑
ZHENG WEI / 大一
